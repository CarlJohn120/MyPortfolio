My Journey Into Front-End Development

When I first started learning HTML and CSS, I didn't think I would enjoy it this much. It all began in my IT 101 class where we had to revamp the Arngren website. That project really opened my eyes to how important good UI design is.

Working on the Arngren project taught me about visual hierarchy, spacing, and making things look clean and simple. I realized that front-end development isn't just about making things look pretty — it's about making things easy to use.

Since then, I've been learning more about responsive design using Bootstrap and exploring Python for some backend stuff. Still a long way to go, but I'm enjoying the process!

Student Life January 15, 2026 2 min read

Passing the Civil Service Exam

One of my proudest achievements so far was passing the Civil Service Professional Exam back in 2024. It was honestly a tough experience balancing review sessions with school work.

I studied mostly during weekends and tried to stay consistent with my review schedule. If you're a student planning to take it, my advice is: start early and don't cram. It really helps to have a study plan.

Getting that eligibility felt great, and it's nice to have that checked off while still in college.

Building MySafety — A DRRMO Website Proposal

For our Software Engineering 2 class (CSC 107), our team worked on MySafety — a proposal for a responsive DRRMO website for the university. The goal was to help increase environmental disaster preparedness among students and staff.

As the front-end developer, I was responsible for designing the layout and making sure the site was mobile-friendly. We used HTML, CSS, and Bootstrap for the responsive design. It was a great learning experience working with a team and going through the software development lifecycle.

The project taught me a lot about real-world web development — from gathering requirements to actually building something that could help people.

Projects March 10, 2024 3 min read

Designing a Booking Platform for Travelers

For Software Engineering 1 (CSC 106), I led the UI design for a traveler-focused booking platform. We wanted students and backpackers to quickly compare itineraries, reserve stays, and get curated tips without hopping between multiple tabs.

The sprint started with user interviews and simple journey maps to understand what stresses travelers the most. From there I built low-fidelity wireframes in Figma.

This project pushed me to balance clean visuals with complex booking data. It also set the foundation for growing TourMe into a more complete travel companion in future iterations.
